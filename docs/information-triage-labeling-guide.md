# 学业信息分诊：人工标注规范 v0.1

> 日期：2026-10-28
>
> 状态：55 条匿名改写样本已完成两轮独立标注草案；真人复核仍待完成，真实数据 Gold Set 尚未关闭

## 1. 目的

这份规范用于建立 Cove 的人工 Gold Set。它回答的不是“模型总结得像不像”，而是产品是否真的能替学生完成第一轮巡检和筛选。

Gold Set 后续同时服务三件事：

1. 验证信息分诊是否存在真实价值；
2. 比较规则、提示词和模型版本；
3. 为简历提供可核验的产品判断与迭代证据。

## 2. 隐私边界

- 不把真实姓名、邮箱地址、学号、令牌、Cookie 或完整私人正文提交到 Git。
- 仓库只保存匿名样本、必要证据片段和哈希化样本 ID。
- 引用片段只保留支持判断的最短句子，并移除个人身份信息。
- 原始内容仍留在受控数据源中；公开 Demo 使用改写后的合成样本。

## 3. 标注单位

基本单位是一条可独立阅读的内容：一封邮件、一个 Ed 主题、一个 Moodle 公告或一个 assessment。

如果一个 Ed 主题在教师回复后改变了结论，应把“主题首帖”和“教师最终回复”作为同一信息单元的两个证据部分，不把学生提问本身当作正式要求。

## 4. 必填字段

| 字段 | 说明 | 示例值 |
|---|---|---|
| `sample_id` | 匿名稳定 ID | `ed-001` |
| `source` | 数据来源 | `gmail` / `ed` / `moodle` |
| `course` | 课程；无法判断则为空 | `FIT1047` |
| `content_type` | 内容类型，见下文 | `staff_answer` |
| `authority` | 信息权威性 | `staff` / `system` / `student` / `unknown` |
| `importance` | 用户是否值得看到 | `critical` / `important` / `reference` / `skip` |
| `action_required` | 是否明确要求用户行动 | `yes` / `no` / `uncertain` |
| `action_text` | 如果需要行动，用一句话说明 | `完成课程反馈问卷` |
| `time_text` | 原文中的时间要求；没有则为空 | `本周末前` |
| `summary_gold` | 忠于原文的一句话结论 | 匿名化摘要 |
| `evidence_quote` | 支持结论的最短原句 | 匿名化关键句 |
| `open_original` | 用户是否应打开原文 | `required` / `optional` / `no` |
| `duplicate_group` | 语义重复组；没有则为空 | `dup-003` |
| `uncertainty_reason` | 无法确定的原因 | `尚无教师回复` |

## 5. 内容类型

| 类型 | 定义 |
|---|---|
| `required_action` | 明确要求学生提交、填写、参加、修改或确认 |
| `requirement_change` | 截止时间、提交方式、评分或任务要求发生变化 |
| `staff_announcement` | 教学人员发布的重要课程通知，但不一定要求行动 |
| `staff_answer` | 教师对学生问题给出的可复用结论 |
| `peer_question` | 学生提问，尚无权威答案 |
| `learning_material` | 新增课件、录播、阅读或复习材料 |
| `assessment_fact` | Moodle 等系统提供的结构化 assessment 事实 |
| `administrative` | 学校或课程行政信息 |
| `promotion` | 活动、营销或非必要推广 |
| `noise` | 与当前学习判断无关、重复或无有效内容 |

## 6. 重要性判断

### `critical`

错过后可能造成提交失败、迟交、失去资格或明显影响成绩；或者内容明确改变已知要求。必须展示证据，不能只给摘要。

### `important`

与课程安排、作业理解或教师正式说明直接相关，值得在本次简报中展示，但不一定立即行动。

### `reference`

以后可能有帮助，例如一般学习材料或未形成结论的学生讨论。默认折叠，可按课程查看。

### `skip`

当前不值得占据简报注意力，例如无关推广、空内容、重复副本或低相关讨论。

## 7. 判断规则

1. **权威性优先于措辞强烈程度。**学生说“必须”不等于课程要求；教师或系统来源才可支持正式结论。
2. **行动与重要性分开。**一条信息可能很重要但无需立即行动，也可能要求一个低风险可选动作。
3. **事实与推断分开。**无法从证据直接支持的内容写入 `uncertainty_reason`，不补全成确定结论。
4. **重复不等于删除。**跨来源重复内容合并展示，但保留全部来源和更权威版本。
5. **时间字段按语义解释。**邮件和 Ed 的 `timestamp` 通常是发布时间；Moodle assessment 的 `timestamp` 可能是截止时间，不能直接混用。
6. **个性化暂不伪装成通用规则。**只对某个学生或小组有意义的内容标记其适用范围。

## 8. 首批样本配额

首批至少 50 条，建议用 55 条留出无效样本：

- Gmail 已归属课程：15 条；
- Gmail 未归属课程：10 条；
- Ed 学生主题：15 条；
- Ed 教学人员主题或含教师回复的主题：10 条；
- Moodle assessment 或公告：5 条。

至少覆盖：行动要求、重要更新、教师答复、学生讨论、学习材料、推广、跨源语义重复和不确定内容。

## 9. 标注流程

1. 第一轮只看标题、来源、作者角色和短摘要，完成初判。
2. 对 `critical`、`important` 和 `uncertain` 样本回到原文核对。
3. 隔一天进行第二轮复标，记录判断变化，而不是静默覆盖。
4. 对分歧样本写出采用规则，并更新本规范。
5. Gold Set 定稿后再运行模型基线，避免用模型输出反向污染人工答案。

## 10. 第一版评测指标

- **重要信息召回率：**人工标为 `critical/important` 的内容，有多少被系统展示。
- **关键误报率：**系统置顶的内容中，有多少人工认为应为 `reference/skip`。
- **低价值压缩率：**人工标为 `reference/skip` 的内容，有多少被正确折叠。
- **摘要忠实度：**摘要中的每个关键结论是否有原文支持。
- **课程归属准确率：**课程判断是否正确。
- **权威性准确率：**是否正确区分系统、教学人员和学生内容。
- **语义重复准确率：**跨来源同一事项是否正确合并且未误合并。

第一版优先保证重要信息召回率和摘要忠实度；宁可把少量低价值内容带入简报，也不能为了“压缩得漂亮”漏掉高影响信息。
