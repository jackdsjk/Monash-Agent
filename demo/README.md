# Cove 匿名演示

一个零依赖的浏览器原型，用 55 条匿名改写样本演示 Cove 的第一版信息分诊体验：

- **自上次查看**：只看最近一段时间的更新；
- **注意力分组**：必须处理 / 教师答复 / 重要更新 / 新资料 / 已折叠；
- **原文证据**：每条结论都展示模型引用的原文句；
- **用户纠错**：置顶、折叠、反馈分类问题，状态保存在本机；
- **详情面板**：查看全文、模型字段和证据高亮；
- **空状态与模拟同步**：演示“检查完之后没有新内容，下一次同步再出现”。

## 运行

在仓库根目录启动一个静态文件服务器：

```bash
python3 -m http.server 4173 --directory demo
```

然后打开 <http://127.0.0.1:4173/>。

也可以使用任意静态服务器；不要直接双击 `index.html`，因为浏览器会拦截 ES module 的本地导入。

## 交互

| 操作 | 效果 |
|---|---|
| 左侧「自上次查看 / 全部内容」 | 切换时间窗口 |
| 来源按钮 | 筛选 Gmail、Ed、Moodle |
| 搜索 | 搜索标题、课程和原文 |
| 只看需要行动 | 只留下 `action_required=yes` 或 `critical` 的内容 |
| 标为重要 / 不重要 | 写入本机 `localStorage`，卡片立即移动分组 |
| 查看原文 | 打开详情，查看全文和高亮证据 |
| 反馈这条判断 | 选择原因并写说明；仅本机保存 |
| 标记本次已查看 | 清空“自上次查看”窗口，进入空状态 |
| 模拟同步 | 演示下一次巡检返回 1.5 小时内的新内容 |
| 重置演示 | 清除所有本机状态 |

快捷键：`/` 聚焦搜索，`Esc` 关闭详情。

## 数据边界

- 数据来自 [gold-set-samples-2026-10-28.json](../docs/gold-set-samples-2026-10-28.json) 的 55 条匿名改写样本；
- 分诊字段来自 [gpt-5.6-luna 模型回放记录](../docs/model-eval-gpt-5.6-luna-2026-10-29.md) 的预录快照；
- 没有真实账号、真实原文链接、实时模型调用或后端服务；
- 演示中的“多久以前”是相对于页面打开时间的合成时间，用于展示 Since Last Check；
- 模型判断有错误，这是演示的一部分，不是人工复核后的 Gold Set。

## 结构

```text
demo/
├── index.html          # 页面骨架
├── styles.css          # 设计、响应式和可访问性样式
├── data/items.js       # 55 条匿名样本 + 预录模型输出
├── js/core.js          # 纯展示规则：分组、筛选、摘要、转义
├── js/app.js           # 状态、DOM 渲染、交互和 localStorage
└── test/core.test.mjs  # 数据完整性和纯逻辑测试
```

## 验证

```bash
node demo/test/core.test.mjs
```

## 已知边界

- 这是浏览器原型，不是 Electron 桌面壳；
- 没有实现真实登录、同步、来源跳转或后端持久化；
- 没有展示跨源语义去重、日历提醒、问答和 MCP 入口；
- 当前数据量只适合验证交互方向，不能代表真实用户效果。
